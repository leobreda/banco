# banco

Aplicativo pra demonstrar um banco, com as seguintes opções:

- Cadastro de conta
- Saldo
- Depósito
- Saque

## Instalação
Execute o script install.sh
```
./install.sh
```
Nota: execute o script somente 1 vez. Nas demais vezes, o script irá criar um novo banco de dados.

## Carregue a API
Mantenha o script api.sh em execução
```
./api.sh
```
Você também pode abrir o site https://localhost:7220/swagger/index.html , caso queira ver a API no browser

## Carregue o front end
```
./front.sh
```
